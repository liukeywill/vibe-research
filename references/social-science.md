# 社科研究执行要点

根据实际问题选择方法，不根据已安装工具倒推方法。

| 研究类型 | 最小可执行材料 | 分析与限制 |
|---|---|---|
| 文献综述 | 明确问题、检索式、筛选记录、可审阅来源 | 区分叙述综述、范围综述、系统综述；不把便利搜索称为穷尽检索 |
| 问卷/计量 | 真实数据、变量字典、抽样与缺失情况 | 先确定分析单位与设计；检查测量、混杂及模型假设；横截面关联不写因果 |
| 访谈/田野 | 经授权的记录、采集背景、匿名化方案 | 可追溯编码、反例、研究者反思；不得自动把零散访谈当总体频率 |
| 比较案例/文旅案例 | 案例边界、选择理由、原始材料及可比维度 | 区分制度文本、实际执行与受访者评价；不以单一成功案例推断普遍效果 |
| 理论/概念 | 概念来源、边界、竞争解释、相关研究 | 把论证、命题与实测发现分别标明；可证伪条件或适用边界必须可理解 |
| 政策分析 | 正式文件、有效日期、发布机构及实施资料 | 核实版本及适用范围；政策目标与实际成效分开 |

研究问题卡至少写：对象、范围、现象/关系、学术或实践意义、已有证据、缺失证据、可能的反例、最小下一步。选题阶段不要为凑“创新点”宣称理论首创。

数据分析前只对会改变结论的缺项集中询问。未获得数据时可自动准备变量表、分析脚本骨架或访谈提纲；明确这些属于研究准备。使用模拟数据测试代码必须单独保存并标注“演示数据”，不得混入实测结果。

已读摘要与已读全文分别记录。元数据检索用来找文献；论断核验须查看真正支持该语句的章节、页码、表格或原始材料。无 DOI 的中文期刊、政策和档案可以用可信来源核验，不因缺 DOI 直接排除。
