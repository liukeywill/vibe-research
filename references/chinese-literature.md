# 中文文献与知网

## 数据源选择

中国情境论文并行检索中文与英文研究。按问题构建中文同义词、对象词和机制词，记录实际执行的检索式、范围、年份、排序、日期、结果数量及已查看页数。不硬设中文引用比例；优先覆盖最贴近问题的国内理论、方法和实证研究，主动查找反例。新闻与政策独立记录，不能计为中文学术研究覆盖。

知网是文献发现和题录核验来源；期刊官网、作者开放版本和用户有权提供的材料可补充正文。不同来源命中同篇论文保留获取记录，按 DOI 或实际一致的题名、作者、年份核对身份。中文 DOI 不在 Crossref 中并不证明论文不存在；DOI 存在也不证明题名或论断正确。

## 知网浏览器执行

使用本环境的 cua_repl 浏览器工具。从 https://www.cnki.net/ 进入，按当前可见控件提交查询，观察结果后再筛选学术期刊、年份和学科；不得照抄历史选择器或伪造私有 API。每次交互后核对页面状态。

2026-10-06 实测：首页主题检索“历史街区 城市更新”跳转到 kns.cnki.net/kns8s/defaultresult/index；页面显示总库 4,109 条、学术期刊 1,614 条（当时尚未筛选），可见题名、作者、来源、发表日期、数据库类别、引用和导出与分析入口。该数量是页面报告的混合库命中量，不是已获取、筛选或精读数量，也不能推断全部相关。随后出现拼图安全验证，下载按钮提示未登录。因此仅首页查询和结果显示经过实测，详情、导出、全文及登录后持续运行尚未验证。

遇验证码记录 blocked/captcha_required；默认自动成稿立即切换其他可访问来源，不要求用户完成。仅用户已明确选择交互式知网检索时保留页面供用户自行处理；不自行解题或绕过。遇全文权限提示记录 login_required 或 needs_institution，用户可在官方页面自行登录已有个人或机构账号；不要要求粘贴密码、Cookie 或令牌。需要购买的资料不得自动付费。题录仍可保留，继续期刊官网的开放正文路线。

查看详情时实际核对题名、作者、刊名、年份、卷期页、DOI、摘要和关键词。仅结果页不能补造卷期页和摘要。导出功能须按当前可见格式选择并检查真实文件，保留原始导出；本工作台目前没有经过实测的知网导出解析器，不宣称自动导入已完成。取得题录后按现有 search-results/sources schema 归一化，保留原页面 URL 与核验时间，不添加 schema 不允许的字段；扩展获取日志可作为附件保存。

全文须确认是目标论文正文且已实际读取，才能登记 fulltext、read_scope 和定位证据。可下载不等于开放获取，CAJ 不改后缀冒充 PDF。只有题录或摘要时保持相应访问级别，不能登记为全文核验；参考文献正文论断仍受现有证据门槛约束。

## 工作台衔接与完成条件

search → 中文候选与英文候选合并 → 去重和纳排复核 → 实际全文阅读 → 横向对比 → 修订研究空白、框架与正文 → 引用和 Word 检查。验证码与授权是明确人工介入节点，不保证知网访问全程无人值守。

将检索受阻、未读全文和缺失题录字段写入 search-log/reading-notes；不得把受阻当作零命中。核查中文学术证据是否真正支撑核心论断，不能只在文末增加条目。已完成项目补充证据后应依原冻结运行时重新推进失效阶段；需要新运行时代码时建立新版本项目，保留原稿和证据。

未来如接官方 API，须先核对知网提供的真实产品权限、文档、认证和返回字段，再按 DataSource 接口实现并实测；第三方 MCP 仓库的功能说明不代表本机已连通。当前 ARS chinese_literature_client 主要通过 DOI/Handle/PubMed 核验部分中文题录，不提供知网主题检索，也不能替代此流程。
