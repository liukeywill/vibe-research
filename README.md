# Vibe Research 科研工作流

输入研究方向，从选题到最终核验分阶段推进科研。AI 协助探索、检索、设计、执行与写作，研究者保留问题选择、方法判断、证据核查和结论取舍。

## 快速开始

```text
$vibe-research 我的研究方向是：AI辅助科研写作。
```

不必先填完整表格。助手建立项目卡，从当前可开展的阶段开始，交付具体成果和人工核查清单。已有方案、数据或初稿时可进入对应阶段，但不会把缺失的前置核查写成已通过。

## 完整八阶段

| 阶段 | 主要成果 | 人工核查重点 |
|---|---|---|
| 1 问题收敛 | 候选问题比较、研究问题说明书 | 重要性、范围、可回答性与资源；研究者选题 |
| 2 文献证据 | 检索记录、文献矩阵、候选缺口 | 原文存在、语义支持、反对证据与检索盲区 |
| 3 研究设计 | 方案、假设、指标与分析计划 | 方法能否回答问题、替代解释、关键参数与适用权限 |
| 4 最小验证 | 试验或推导报告、真实输出 | 实际执行、手工复算、关键失败风险与是否扩大研究 |
| 5 正式执行 | 数据、代码、分析、日志与复现说明 | 数据处理规则、关键结果复算、偏离与负面结果 |
| 6 论证写作 | 主张—证据表、提纲与初稿 | 先确认论证表，再核查初稿的证据、引用和结论强度 |
| 7 评审修订 | 意见表、作者决定、修订与复核记录 | 先审查意见，再由研究者逐项取舍，之后才修订 |
| 8 最终核验 | 最新定稿、核验报告与材料索引 | 版本对应、核验覆盖、剩余局限与最终接受 |

每阶段的完整提示词、交付物、人工核查项与通过条件见 [references/stages.md](references/stages.md)。阶段 6、7 的人工决定子步骤也完整保留。

## 人工核查与推进

每阶段交付后停在本阶段，列出成果、3—6 个具体人工核查问题、待决定项和下一步建议。研究者可以确认、要求修改、换题、回退或暂停。

```text
阶段1已核查，采用方案B，继续。
```

单独回复“继续”只授权推进，不代表逐项核查通过；未回答项继续保留“未核查”。必要方案未选或关键结论无依据时，不执行依赖该决定或结论的工作。AI 自检不能记作人工确认。

## 进度保存与恢复

默认在当前工作目录下的 `research-projects/<项目短名>/` 保存项目卡、状态、人工决定和阶段成果。状态字段及转换规则见 [references/project-state.md](references/project-state.md)。

```text
$vibe-research 继续 /你的项目绝对路径/research-projects/项目名
回到研究设计阶段，调整主要指标。
暂停并给我恢复摘要。
```

恢复时核对文件与版本；上游发生实质变更，将受影响下游标为待复核，保留历史成果和决定。
